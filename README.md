# Аналітика та контроль якості виробництва

Цей проєкт є інтерактивною аналітичною системою (BI-дашбордом) для моніторингу ефективності збірки, оцінки якості роботи інженерів та аналізу логістичних витрат на базі згенерованого масиву виробничих логів (1000+).

## 🚀 Основні етапи реалізації

1. **Моделювання даних:** 
   Розроблено реляційну модель даних «Зірка» (Star Schema). Усі щоденні логи збірки та складські записи комплектуючих підключено до центральних довідників компонентів та дат, що мінімізує дублювання інформації та забезпечує миттєве оновлення звітів.

2. **Power Query:**
   Спроєктовано та реалізовано повний безперервний календар (таблицю дат) мовою M. Це дозволило зв'язати місячні плани керівництва із щохвилинними логами конвеєру.

3. **Аналітичні розрахунки (DAX):**
   * Створено міру **FTT Rate (First Time Through)** — ключовий показник якості, що відображає відсоток *, які успішно пройшли тестування з першого разу без помилок збірки.
   * Написано фінансову метрику **Financial_Loss_USD** (з використанням функцій `SUMX` та `RELATED`), яка автоматично розраховує збитки підприємства від бракованих деталей на основі їх собівартості зі справочника компонентів.

## 📊 Які управлінські рішення дозволяє приймати дашборд:
* **Аналітика якості:** Відстежувати стабільність збірки по днях, виявляти аномальні просадки якості та контролювати FTT кожного інженера окремо через інтерактивні фільтри.
* **Аналіз План-Факт:** Порівнювати реальні обсяги випуску з плановими нормативами у розрізі місяців для коригування завантаження ліній.
* **Оптимізація поставок:** Оцінювати фінансові втрати від браку комплектуючих та бачити чіткий рейтинг найменш надійних постачальників (зокрема, виявлено критичний рівень збитків через дефекти деталей компанії *MatrixTech*).
